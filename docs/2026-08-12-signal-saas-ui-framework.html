Foundation · 设计基础

signal-saas 视觉语言

基于 free-trading-system 设计库扩展。深海军蓝画布承载数据密度， 电光青绿 #00d4aa 作为唯一品牌高亮色。锐利圆角、玻璃态面板、 Space Grotesk + JetBrains Mono 双字体系统。整体是"专业交易仪器"而非"消费级产品"。

Brand Differentiation · 品牌差异

"信号波" 概念

与纯交易终端的差异：本平台是信号聚合者。品牌视觉核心是 信号波——代表跨 5 所聚合的信号流、实时推送的生命力。 用于：品牌 logo 波纹、加载状态、首页英雄区背景、策略卡片活跃指示。

信号波动画（品牌签名元素）
品牌 mark：signal-wave · 首页 hero 背景网格 + 波脉冲 · 加载器动画复用此路径
VOICE

Rules · 设计规则

实施约束

DO
必须遵守
01策略/界面不出现任何交易所 Logo 或名称（合规）
02所有金额/价格用 JetBrains Mono + tabular-nums
03涨跌语义色：绿=盈利 / 红=亏损 / 黄=风控告警
04状态必须 颜色 + 短标签，永不单用图标
05风险揭示模态框（RiskModal）强制不可跳过
06API Key 输入框 mono 字体 + 打码 + 拒提现提示
DON'T
禁止
01紫色渐变、圆润友好型卡片、消费级糖果色
02emoji 作为界面图标（用线性 SVG）
03收益承诺文案（"稳赚""保本"违反合规）
04后台复用前台登录体系（完全隔离）
落地到开发计划
UI 框架冻结后，M5 前台任务与后台任务按此组件系统实施。theme-factory 可基于本框架生成主题；组件命名遵循 web-ui/components/ 既有清单。
