Rules · 设计规则

补充设计规则

DO
后台与邀请页强制约定
01 后台登录页必须有 ADMIN CONSOLE 红色警示标识，与前台视觉区分
02 后台写操作二次确认 + audit-log 记录，敏感操作红色警示按钮
03 邀请页金额全部等宽字体 + 状态徽章；核实倒计时实时更新（WS reward.tick）
04 邀请码分享按钮触发系统原生分享；复制成功 Toast 反馈
05 时间轴组件统一规范：完成✓绿 / 进行中脉冲 / 待开始灰
