# M8 功能变更记录：跟单阀门 + 邀请码复核免订阅 + 采集稳定性（2026-08-24）

> 对应提交：`a458afc`（跟单阀门）、`d0841a3`（邀请码选填与复核）、`9ab89b1`（后台导航调整）及此前未推送的采集稳定性系列（`fbb4022`/`080bec8`/`939a111`/`249ce94`/`f475482`/`b99c54a`/`015b4f7`）。

## 1. 跟单阀门后台化（follow_enabled）

**背景**：此前"隐藏仓位策略不可跟单"由 `hide_position` 隐式推导，管理员无法显式控制策略是否可被跟单。

**改动**：
- `Strategy` 新增 `follow_enabled` 字段（迁移 `j9e0f1a2b3c4`），后台管理员显式开关
- 后台「信号源审核」页三表（待选池/已上架/搜索）新增开关，上架弹窗按模式提示
- 前台策略广场/详情按 `follow_enabled` 显示「开启跟单」按钮，关闭时显示"仅展示"提示
- 模式判定持久化读 `Strategy.source`，防 A/B 基线互污染乒乓假信号

## 2. 邀请码选填 + 管理员复核免订阅

**背景**：注册时两个邀请码原为必填，改为选填；交易所邀请码绑定后需管理员复核通过才免订阅。

**改动**：
- **注册选填**：交易所邀请码、好友邀请码均改为选填可跳过；交易所码注册后可随时补填，好友码仅限注册后 24h 内绑定（不允许事后补填）
- **交易所邀请码预设**：后台「交易所邀请码」页预设多个码（分所、绑定上限、启停用）
- **复核链路**：用户绑定后进入 `pending` 待复核（迁移 `k2b3c4d5e6f7` 新增 `exchange_invite_status`，存量回填 pending）→ 后台「用户绑定复核」面板批准/驳回（审计留痕 + 站内通知）→ 批准后才免订阅；驳回可重新绑定（释放旧码计数）
- **免订阅判定**：`subscriptions/me`、建跟单闸门、风控闸门三处统一以 `approved` 为准；`/v1/identity/me` 透出复核状态
- **前端展示**：订阅页「复核中」黄卡 + 驳回提示；账户页概览卡显示已生效/待复核/已驳回，驳回可重绑
- **后台导航**：交易所邀请码入口移至「运营」组主号审核旁（原藏于「合作」组）

## 3. 信号采集稳定性与延迟优化

- 批量任务独立浏览器 profile（`scraper-bulk`）与 `poll_live` 隔离，消除 ProcessSingleton 抢锁
- beat 调度改 crontab 固定相位，消除 timedelta 相位漂移撞车
- `refresh` 兜底通道：无监控策略写 A 基线 + 持仓差分展示 + trading_view 历史行入库
- 信号轮询提速 5s → 2.1s/轮（展示缓存按交易员节流 10s），实测 828 条信号识别延迟 p50=0.43s / p90=0.93s / p99=2.78s
- 平仓/减仓信号豁免延迟红线（close/reduce 是风险释放，迟到平仓好过永不平仓）
- `copy_orders` 新增 `created_at` 落库时间 + 失败原因落库（`fail_reason` 列）
